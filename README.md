# Cookie Clicker

Небольшая веб-игра на JavaScript: кликайте по печенью, покупайте улучшения и разгоняйте производство.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Файлы

- `index.html` — разметка игры.
- `styles.css` — адаптивный интерфейс и визуал печенья.
- `app.js` — игровая логика, улучшения и сохранение прогресса в `localStorage`.
