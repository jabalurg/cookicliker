# Jump Runner

Небольшая веб-игра на JavaScript: прыгайте девочкой, набирайте серию и получайте больше очков за каждый прыжок.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Файлы

- `index.html` — разметка игры.
- `styles.css` — адаптивный интерфейс и визуал печенья.
- `app.js` — игровая логика прыжков и сохранение прогресса в `localStorage`.

## Управление

- Кнопка `Прыжок`, `Space` или `ArrowUp` — прыжок девочки и очки за серию.
